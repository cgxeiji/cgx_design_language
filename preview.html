Buttons

Buttons share a base .cgx-button class with specific variant classes for purpose.

Cards

Cards are flexible containers used to group related content and actions.

Base Card

The default card uses the --cgx-element-bg and has no visible border. It sits flat on the background.

Outlined Card

Uses Bright White at 10% opacity for a sharp, modern edge against dark backgrounds.

Interactive Card

Hover or focus me! Moves up 2px and gets a solid white border to indicate it is clickable.

CTA Card

The ultimate Call-to-Action. Features a slow-rotating, multi-colored border gradient (orange to yellow).

Panels

Panels are simple, nestable containers used to group UI elements or layout sections without imposing rigid internal structures.

Base Panel (Outlined)

Uses a 30% transparent white border with 16px padding. A simple, flexible container for grouping content.

Ghost Panel

Uses a 30% transparent dashed white border. Excellent for empty states or drop zones.

Collapsible Panel

This content is hidden by default. Click the summary header to reveal it.

Because this uses the native HTML <details> and <summary> tags, it requires zero JavaScript to function and maintains perfect accessibility.

Tabbed Panels

Tabbed panels organize content into switchable panes. The tab bar can be placed on any edge using directional variant classes. Override tab width with --cgx-panel-tab-width.

Default (Top Tabs)

This is the Overview pane. Tabbed panels can hold any nested content like buttons, other panels, or forms.

Charts & Plots

The .cgx-plot canvas element renders one or more data series as linear line charts. Provide data via data-series as a JSON array of arrays. Colors cycle automatically through the CGx palette. The chart is responsive and redraws on resize. External code can push live data by updating data-series and calling canvas._cgxRedraw().
